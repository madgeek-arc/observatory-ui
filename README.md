# EOSC Observatory UI

Web frontend of the EOSC Observatory platform. It presents the open-science monitoring dashboards (country pages,
explore, EOSC readiness, archive), hosts the contributions area where stakeholders, coordinators and administrators
fill in surveys and exchange messages, and generates the country-readiness report.

```
Component:     EOSC Observatory UI (observatory-ui)
Type:          Frontend application
Status:        Production
Technology:    Angular 22 / TypeScript 6.0 / RxJS 7 / Less, UIkit, Angular Material, Highcharts
API:           Consumes the EOSC Observatory API (/api); exposes none
Swagger:       n/a (frontend)
Deployment:    Docker (Node build stage, nginx runtime)
Documentation: /docs
```

## Role in the platform

`observatory-ui` is the single-page application users open in the browser. It holds no business logic or
persistence: every dataset, survey, user and message is read from or written to the Observatory backend under `/api`.
Chart data comes from the Observatory statistics endpoint (`/api/statistics/`) and from the OpenAIRE stats-tool.

The application is assembled from this repository plus three Git submodules, each with its own repository and
documentation:

| Submodule | Path | What it provides |
|---|---|---|
| [survey-tool](https://github.com/madgeek-arc/survey-tool) | `src/survey-tool` | Contributions dashboard, surveys, user/session services, invitations |
| [messaging-system-ui](https://github.com/madgeek-arc/messaging-system-ui) | `src/messaging-system-ui` | Inbox/outbox, threads, public contact form |
| [catalogue-ui](https://github.com/madgeek-arc/catalogue-ui) | `src/survey-tool/catalogue-ui` | Dynamic forms, form builder, rich text editor (nested inside survey-tool) |

## Dependencies on other Observatory components and services

| Dependency | Used for | Configured by |
|---|---|---|
| EOSC Observatory backend (`/api`, `/api/websocket`) | Data, authentication, surveys, messaging | `API_ENDPOINT`, `WS_ENDPOINT`, `PLATFORM_API_ENDPOINT` |
| OpenAIRE stats-tool, OS-Europe API | Open-science indicators and public answers | `OSO_STATS_API_ENDPOINT`, `OS_EUROPE_API_ENDPOINT` |
| Joomla CMS pages | About/resources/news content shown in an iframe | nginx `/pages` proxy |
| Matomo, Sentry, Google reCAPTCHA v3 | Analytics (consent-gated), error reporting, contact-form protection | `MATOMO_*`, `SENTRY_*`, `RECAPTCHA_V3_SITE_KEY` |

See [docs/integration.md](docs/integration.md) for details.

## Prerequisites and local start

- Node.js 22.22.3+ (the Docker build uses `node:22`) and npm
- The submodules checked out: `git clone --recurse-submodules <repo-url>`, or `git submodule update --init --recursive` in an existing clone
- A running Observatory backend on `http://localhost:8280` (the dev proxy target in `proxy.conf.js`)

```bash
npm ci
npm start          # ng serve with proxy.conf.js, http://localhost:4200
```

Other scripts: `npm run build:prod`, `npm run build:beta`, `npm test` (Karma/Jasmine, needs Chrome).
